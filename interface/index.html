Remote control

            
        

        

            
Contrôlez cet ordinateur depuis votre téléphone. Un QR code crée un lien sécurisé (tunnel chiffré) vers ce PC — vous gardez la puissance des modèles locaux, où que vous soyez.


            
            

                
    
                    
  • Le téléphone n'accède qu'au chat — jamais à vos fichiers ni au terminal.
    • 
                    
  • Le lien reste le même tant que la session est active.
    • 
                    
  • Vous pouvez tout couper depuis ce PC ou depuis le téléphone.
    • 
                

            


            
            

                

                
Scannez ce QR code avec l'appareil photo de votre téléphone.
