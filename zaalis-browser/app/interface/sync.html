Synchronisation

Retrouvez vos données sur tous vos appareils

Sans compte ni serveur : choisissez un dossier déjà partagé entre vos ordinateurs (OneDrive, Google Drive, Dropbox, clé USB, partage réseau…). Tout est chiffré de bout en bout avec votre phrase secrète : le service de stockage ne voit jamais vos données.
Si le dossier contient déjà un coffre zaalis, la phrase secrète doit être identique : vos données seront fusionnées. Phrase secrète oubliée : elle ne peut pas être récupérée (il faudra effacer les données de synchronisation).
