# zaalis Glyphes — mini-rapport (19/11/2026)

## Ce que c'est
Les **Glyphes** sont des assistants personnels autonomes. Un Glyphe est un polygone arrondi avec deux yeux ovales : il reste à sa place, mais tourne la tête, bouge les yeux, cligne et s'incline selon son état (au repos, au travail, en attente, terminé, erreur, en pause). Il existe en 12 déclinaisons : nova, iris, corail, ambre, jade, azur, onyx, perle, sakura, menthe, solar et cobalt.

Les Glyphes tournent 24 h/24 sur une VM Google Cloud gratuite. On les pilote depuis :
- le téléphone : une appli web installable, sur https://34-63-15-174.sslip.io ;
- zaalis Labs IDE : **Outils › Glyphes**, qui ouvre la même interface dans une fenêtre centrée.

## Comment ça marche
```
Téléphone (PWA) ──HTTPS──▶ Caddy (Let's Encrypt, sslip.io) ──▶ serveur Glyphes (Node 24, port 8787 local)
IDE  ──/api/glyphes/proxy/*──▶ même serveur, avec un jeton d'appareil chiffré   │
                                                                                 ├─ SQLite (comptes, Glyphes, messages, actions, tâches planifiées)
                                                                                 ├─ Google : Gmail, Agenda, Tasks, Docs (notes) via OAuth
                                                                                 ├─ Modèles : ceux de l'IDE (clés et abonnement ChatGPT)
                                                                                 └─ whisper.cpp (dictée), Web Push (notifications)
```

**Un Glyphe au travail.** Chaque message lance un tour d'agent : jusqu'à 10 étapes d'outils, avec une file par Glyphe. Le Glyphe peut envoyer plusieurs messages d'affilée, planifier des rappels (une fois, chaque jour, en semaine, chaque semaine, chaque mois) et afficher une fenêtre centrée cliquable pour Google Maps ou une page web.

**Modes.**
- **Supervisé** : toute action qui modifie quelque chose (envoyer un e-mail, créer un événement, cocher une tâche…) ouvre une mini-fenêtre au-dessus du chat, avec **Confirmer / Refuser**.
- **Autonome** : le Glyphe agit sans demander.
- **Règle stricte, quel que soit le mode** : une suppression définitive exige toujours un clic de ta part. C'est le cas de la suppression d'un événement ou d'une tâche. Gmail est connecté avec l'autorisation `gmail.modify` et non avec l'accès complet `mail.google.com`. Les e-mails peuvent donc aller à la corbeille, mais aucun ne peut être supprimé définitivement, même par erreur.

**Comptes.** Tout le monde partage la même VM gratuite, mais chaque compte est séparé : connexion Google, données cloisonnées par utilisateur, et secrets chiffrés en AES-256-GCM avec une clé propre au serveur.

**Lien avec l'IDE.** Dans Outils › Glyphes, clique **Relier mon compte Glyphes**. Le navigateur s'ouvre sur la page d'approbation Glyphes ; tu cliques **Autoriser** et l'IDE reçoit un jeton d'appareil (chiffré dans ton profil). Le bouton **Envoyer mes modèles de zaalis Labs IDE** (Paramètres › Modèles) pousse vers le serveur les clés et fournisseurs de l'IDE (OpenAI, Anthropic, Gemini, Grok, Mistral, Kimi, fournisseurs compatibles). L'abonnement ChatGPT se connecte depuis le panneau Modèles de Glyphes, avec un code d'appareil.

## Infrastructure (100 % offre gratuite Google Cloud)
- VM `glyphes` : e2-micro, us-central1-c, Debian 13, disque **standard** 30 Go, sans sauvegarde payante ni agent Ops, avec 1 Go de swap.
- Adresse gratuite `34-63-15-174.sslip.io`, certificat Let's Encrypt automatique via Caddy.
- Service systemd `glyphes`, qui tourne sous l'utilisateur `glyphesd` ; données dans `/var/lib/glyphes` ; réglages dans `/etc/glyphes.env`.
- API activées : Gmail, Calendar, Tasks, Drive. Application OAuth « zaalis Glyphes » **en production, non vérifiée** : écran d'avertissement Google, 100 comptes maximum, et pas d'expiration à 7 jours.
- ⚠️ L'IP est éphémère : si la VM est arrêtée puis relancée, elle peut changer, ce qui casse l'adresse et la connexion Google. Pour l'éviter : Réseau VPC › Adresses IP › « Promouvoir en adresse statique » (même prix tant qu'elle reste attachée à la VM).
- ⚠️ L'offre gratuite couvre la VM, le disque et 1 Go de trafic sortant par mois. Google ne dit pas clairement si l'adresse IPv4 publique est gratuite (sinon, environ 3 $/mois). Je conseille une alerte budget à 1 $ dans Facturation.

## Tester sur le téléphone (iPhone)
1. Ouvre **https://34-63-15-174.sslip.io** dans **Safari**.
2. Touche **Partager › Sur l'écran d'accueil**, puis ouvre Glyphes depuis l'icône. C'est nécessaire pour les notifications et le retour haptique.
3. Touche **Continuer avec Google**. Sur « Google n'a pas validé cette application », choisis **Paramètres avancés › Accéder à zaalis Glyphes**, puis coche les accès (Gmail, Agenda, Tasks, Docs).
4. Dans **≡ › Paramètres**, active **Notifications** (tâche terminée, nouveautés) et **Localisation** (itinéraires Maps).
5. Ajoute un modèle :
   - soit depuis l'IDE : Outils › Glyphes › ≡ › Paramètres › Modèles › **Envoyer mes modèles de zaalis Labs IDE** ;
   - soit sur le téléphone : **Paramètres › Modèles › abonnement ChatGPT** (code d'appareil).
6. Essais :
   - « Envoie un mail à … » : la carte Confirmer / Refuser apparaît (mode supervisé) ;
   - « Rappelle-moi ma séance demain à 18 h » : il planifie un message ;
   - « Le chemin le plus rapide pour aller à … » : fenêtre Google Maps.

Sur Android : Chrome › menu › **Installer l'application**, puis les mêmes étapes.

## Mini-rapport — soirée du 19/11/2026 (déployé sur la VM)

**En ligne sur** https://34-63-15-174.sslip.io. Seul /opt/glyphes a été remplacé. /var/lib/glyphes (base, clé, fichiers) est intact. Fichiers servis vérifiés à l'identique (md5). Tests serveur : 8/8.

### Ce qui change
- **Clavier** : la barre de chat remonte au-dessus du clavier. La zone visible suit le clavier, et la conversation défile jusqu'au dernier message.
- **Modèles IA** :
  - La section « Connecter mon abonnement ChatGPT » est retirée. Les abonnements liés à l'IDE ne changent pas.
  - Chaque abonnement a un bouton « ⋯ » qui ouvre un menu : « Sélectionner par défaut » en haut, « Retirer » en bas.
  - Une coche verte marque l'abonnement choisi.
  - « Modèle par défaut » ne liste que les modèles de cet abonnement.
- **Réglages d'un Glyphe** :
  - Les variantes s'adaptent à la largeur de l'écran, environ 4 par ligne.
  - « Supervisé / Autonome » est plus bas, séparé des variantes.
- **Micro** :
  - Nouvelle ligne Paramètres › Microphone : Autorisé / Bloqué / Autoriser. Si c'est bloqué, elle indique le chemin dans Réglages iPhone.
  - Le retour haptique utilise l'astuce de l'interrupteur, qui fonctionne sous Safari.
- **Verre liquide** :
  - Les surfaces sont unies et un peu opaques, sans halo ni cercle lumineux à l'intérieur.
  - Seul un fin liseré de 1 px, très léger, fait le tour. Ses reflets suivent l'inclinaison du téléphone.
  - iOS demande une fois l'accès au mouvement, au premier toucher.
- **Boutons élastiques** (menu, multiprise, « + ») :
  - Ils s'étirent tout de suite dans la direction du doigt. Le côté opposé reste fixe.
  - Au relâchement, ils reviennent avec un petit rebond.
  - Le « + » étire aussi légèrement la barre de chat.
  - Un étirement n'ouvre pas le menu.
  - Le décalage venait d'une règle `:active` qui écrasait l'étirement tant que le doigt restait posé.
- **Accueil d'un nouveau bot** :
  - À la création, le bot salue par le prénom, dit son nom et demande « En quoi puis-je t'aider aujourd'hui ? ». Les mots sont ceux de l'IA, pas un texte figé.
  - Une mini-fenêtre propose 3 suggestions, plus un champ « Ou écris ta réponse… », avec les boutons « Plus tard » et « Commencer par ça ».
  - La réponse s'affiche sous la question, dans un cadre arrondi, puis le bot enchaîne.
  - Le bot peut réutiliser cette fenêtre à tout moment, grâce au nouvel outil `ask_user`.

### Limites
- Le verre est fait en CSS (flou + liseré), pas en réfraction WebGL comme dans le dossier « liquid glass ». C'est le choix le plus fiable sur Safari et le plus léger pour la batterie.
- Le clavier et l'inclinaison n'ont été vérifiés que dans l'aperçu mobile : ils restent à essayer sur un vrai iPhone.
- L'accueil n'apparaît que pour les bots créés à partir de maintenant, et seulement si un modèle IA est connecté. Nova, créé à l'inscription, n'en a pas.
- Une ancienne connexion ChatGPT déjà enregistrée sur le serveur reste utilisable. Seul le bouton de connexion a disparu.

2. Crée un bot et vérifie l'accueil et la mini-fenêtre.
3. Étire le menu, la multiprise et le « + ».
4. Ouvre Paramètres › Microphone.
5. Ouvre Modèles IA et essaie « ⋯ ».
