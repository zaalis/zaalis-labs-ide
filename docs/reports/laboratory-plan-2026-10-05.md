# Experiment engine and laboratory plan — October 5, 2026

1. Keep the Rust engine and host permissions. Record every provider call, including interrupted calls, without double-counting cumulative totals.
2. Normalize token categories, preserve missing measurements, and share a budget across branches.
3. Run isolated VM experiments with project copies, explicit preparation, hypotheses, asserted tests, persistent evidence, a final retest, and shutdown.
4. Index outcomes and failures by user, project, and environment fingerprint. An infrastructure failure does not disprove a hypothesis.
5. Bound concurrency, stop unneeded branches, and support cancellation.
6. Expose the laboratory to agents through a structured tool and to users through VM settings, with weekly, monthly, and yearly statistics.
7. Compare paired runs and show savings only when a comparable baseline exists.
8. Verify contracts, migrations, isolation, budgets, recovery, errors, real VM paths, UI, and Windows packaging. Save evidence and limits.

Validation certifies only scenarios actually run. No universal savings percentage or claim of zero defects should be inferred.
